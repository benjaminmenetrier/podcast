# podcast
Podcast download and post-processing (renaming, tagging).

## Usage
1) Provide url, artist and album in `serverlist`
2) Run `python3 podcast.py`

## Dependencies
Modules:
- `argparse`
- `calendar`
- `datetime`
- `inquirer`
- `json`
- `os`
- `pathlib`
- `re`
- `requests`
- `rss_parser`
- `unicodedata`
- `urllib.request`
